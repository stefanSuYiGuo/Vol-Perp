# Vol-Perp | Rolling Realized Volatility Perpetual

## 金融工程白皮书（V3 增强与精算版）

**定位：**24/7 连续结算与单盘口聚合的纯波动率金融原语

## 一、 执行摘要

本白皮书提出了滚动已实现波动率永续合约（Vol-Perp，Rolling Realized Volatility Perpetual）。该金融原语旨在将已实现波动率从传统期权链的离散结构与场外（OTC）方差互换的高门槛中解耦，转化为一个 24/7 连续交易、流动性集中于单一订单簿的标准化衍生工具。

传统波动率交易长期面临流动性碎片化、OTC 工具门槛过高以及动态 Delta 对冲摩擦较大等约束。Vol-Perp 通过预言机侧的 3D 张量场高频计算与前端单一 1D 永续盘口的结合，有效缓解了上述瓶颈。在当前 V4 最终定型架构中，预言机后台采用 3D-to-1D 张量投影机制（融合时间记忆、跳跃/扩散分离与深度核），在保持前端极佳流动性连续性的同时赋予系统高维抗操纵能力。产品对底层价格的大幅位移具有天然的正凸性（Positive Convexity）。需明确的是，产品并非完全消除时间相关效应：滚动计算窗口会使历史高波动数据逐步退出，平静期指数将自然回落。此外，持有一篮子多头在长期维度下的数学期望通常为负，而做市商通过做空 Vol-Perp 进行动态 Delta 对冲属于**风险调整后的相对价值机会**而非无风险套利。

## 二、 产品定义与市场定位

### 2.1 波动率敞口的重新表达与时间效应澄清

在传统金融体系中，投资者若想表达对未来波动率的观点，通常需要通过期权组合（如跨式 Straddle、宽跨式 Strangle）或场外方差互换（Variance Swap）。然而，买入传统期权意味着投资者必须同时管理一阶方向风险（Delta）、二阶凸性风险（Gamma）以及日历时间流逝带来的时间价值衰减（Theta）。

Vol-Perp 提供了直接针对波动率本身的裸敞口，其标记价格紧密锚定底层资产价格序列在滚动窗口内的已实现波动率（Realized Volatility）。交易者无需在复杂的行权价（Strike Price）与到期日（Expiration Date）矩阵中进行选择，大大降低了建仓与管理成本。

**关于时间效应（Theta）的准确界定：**产品本身不具备传统到期期权那种按日历时间（Calendar Time）线性流逝的静态 Theta 衰减。但在统计学意义上，由于预言机采用滚动时间窗口（Rolling Window）计算已实现波动率，过去发生的极端高波动数据会随着时间推移逐步退出窗口期；在随后的平静行情中，预言机指数会自然回落。这种回落机制反映的是统计因子的"历史高波动退场效应"，而非期权契约的时间到期衰减。

### 2.2 单盘口流动性聚合与架构

- **前端交易层：**所有市场参与者（零售、机构、做市商）集中在同一个 1D 永续合约订单簿中进行挂单与撮合，保持极致的连续性与流动性，避免了传统期权链上成百上千个不同合约导致的流动性稀释。

- **后端预言机层：**预言机基于 3D 张量场（包含时间记忆维度、跳跃/扩散分离维度及订单簿深度核维度）对高频数据进行审视与计算，最终实时投影降维为一个单一的已实现波动率指数（RVI / IP 数字），作为合约标记价格（Mark Price）的锚定基准。

## 三、 需求场景与应用范式

Vol-Perp 适用于多种交易与风险管理场景：

1. **宏观重磅数据发布：**在美联储议息会议（FOMC）、CPI 数据、非农就业报告发布前，市场通常存在剧烈的方向不确定性，但已实现波动率上升概率极高，交易者可直接建仓 Vol-Perp 多头表达方向中性观点。

2. **个股财报季与黑天鹅事件：**高关注度科技股在财报发布前后，隐含与已实现波动率常发生剧烈剧变，Vol-Perp 提供了精准捕获开盘跳空与盘中剧烈抖动的工具。

3. **加密与股票永续合约的跨市场对冲：**在 24/7 连续交易环境中，Vol-Perp 能够实时对冲跨市场系统性风险与尾部黑天鹅。
